## Why, and what changed

`diagnose.py` on the 10-16 transcripts (114 runs per arm): the server arm's
median run cost $0.55 against $0.029 for alt. Output tokens were 55% of its
cost and cache writes 44%. Per run it wrote a median 16,200 characters into
tool calls (the data file, copied from a Read) and got 19,700 characters back
from tools (the Read, the returned alignment, and `top_n` up to 300 on model
selection). Tool definitions were not the cause: the first call's context was
4,900 tokens against 1,900 for Read only, and both arms took a median of 3
turns. The changes: `fasta_path` / `trees_path` inputs, `map_positions` (all 4
of the server's wrong answers were hand counts along an alignment), and
`select_substitution_model(models=[...])`.

One pilot run preceded this file, to check the harness on the git spec: mcp
arm, q13, 1 rep (right, $0.062; it called `map_positions` with a relative
`fasta_path` and did not Read). It is kept apart
(`~/phylokit-mcp-artifacts/agent_qa/rerun-2026-10-18/pilot/`) and is not part
of the analysis.

## Primary endpoint and win rule

Primary endpoint: each question's median cost per answer over its 3 runs
(`total_cost_usd`; every row counts, valid or not, because the money was
spent), mcp against alt.

- **Non-inferior:** mcp's questions right in all 3 runs >= alt's − 2.
- **Better:** an exact two-sided sign test over the 38 questions, on whether
  mcp's median is above or below alt's, has p < 0.05; and the bootstrap 95% CI
  (10,000 resamples of questions, seed 20261016) of the geometric mean of the
  per-question mcp/alt median-cost ratios lies wholly below 1.
- **WIN** = non-inferior and better. **LOSS** = not non-inferior, or mcp
  significantly costlier (p < 0.05, CI wholly above 1). Anything else is a
  **TIE**. Implemented as `analyze.win_rule`, tested in
  `tests/test_agent_qa_controls.py`.

Secondary, reported but not deciding: accuracy, the seconds ratio, cost by
token kind, and the mechanism counts (runs that passed a `*_path`, an inline
payload, `map_positions`, `models`, or called Read). A fix no run used was not
tested.

Expectation, written down so it can be wrong: cost per answer falls by about
ten times, but the server's definitions and structured outputs may keep it
above alt's $0.03, in which case the result is a tie or a loss.
